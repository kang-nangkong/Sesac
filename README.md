# Sesac Project

새싹(Sesac) 팀 공동 프로젝트입니다.

## 프로젝트 소개
- 프로젝트명: 하루
- 팀 구성: 3명
- 목적: 서비스 기획 및 MVP 개발

## 폴더 구조
- docs/: 서비스 기획서, WBS, 정책서
- frontend/: HTML, CSS, JavaScript
- backend/: Python, Flask, API
- data/: 테스트 및 샘플 데이터

## 협업 규칙
- main에는 검토된 결과물만 반영합니다.
- 새로운 작업은 반드시 별도 브랜치를 만듭니다.
- 작업 완료 후 GitHub에 푸시하고 PR을 생성합니다.
- 다른 팀원 1명이 확인한 뒤 main에 병합합니다.
- 작업 시작 전에는 최신 main을 내려받습니다.
- API 키, .env, 개인정보, 실제 건강정보 등은 업로드하지 않습니다.
