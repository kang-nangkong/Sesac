# Sesac Project

새싹(Sesac) 팀 공동 개발 프로젝트입니다.

## 프로젝트 소개
- 프로젝트명: 하루
- 팀 구성: 3명
- 목적: 서비스 기획 및 MVP 개발

## 폴더 구조
- docs/: 서비스 기획서, WBS, 정책서
- frontend/: HTML, CSS, JavaScript
- backend/: Python, Flask, API
- data/: 테스트 및 샘플 데이터

## 협업 규칙
1. main 브랜치는 팀 공용 버전으로 관리합니다.
2. 새로운 기능은 별도 브랜치에서 개발합니다.
3. 작업 완료 후 Pull Request를 생성합니다.
4. 다른 팀원이 변경사항을 검토한 뒤 main에 병합합니다.
5. API 키, 비밀번호, .env 파일은 업로드하지 않습니다.
